# Support

This repository hosts the official AINative Studio client SDKs for React,
Vue, Svelte, and Next.js.

## Getting help

- **Documentation**: https://api.ainative.studio/docs
- **Email**: support@ainative.studio
- **Discord**: https://discord.com/invite/paipalooza
- **Issues**: https://github.com/AINative-Studio/ainative-sdks/issues

Before filing an issue, check your package's README (`react/README.md`,
`vue/README.md`, `svelte/README.md`, `nextjs/README.md`) — most framework-
specific questions (CORS setup, auth, SSR behavior) are already covered
there.

## Reporting a bug

Open an issue in this repository with:

- The package and version affected (e.g. `@ainative/vue-sdk@1.0.0`)
- A minimal reproduction
- Expected vs. actual behavior

## Security issues

Do not open a public issue for a security vulnerability. Email
support@ainative.studio instead.
